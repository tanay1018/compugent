Why not just run the agent every time

An LLM in the loop makes every run a fresh negotiation with the UI. It is slow, it costs money per invocation, and — the part that matters for back-office work — it is not repeatable. The same request can take a different path on Tuesday than it did on Monday, and you cannot audit or approve a process that reinvents itself each time.

So the model is used for what it is genuinely good at: working out how the software behaves, once, by looking at it. What it learns compiles into an artifact — parameters, steps, targets, waypoints, outputs, failure classifications — and from then on the artifact is what runs.

Discovery · minutes, costs tokens

A model drives the surface one action at a time, re-reading the screen after each. Produces a trace.

Determinism is not generalisation

A capability that works only for the value it was recorded on is a recording, and repetition cannot tell the difference — the recorded case passes identically every time. Proving it generalises means replaying it against values it has never seen.

The gate earning its place

A second capability read the temperature off a government weather site. It anchored that value to precededBy "Overcast" — the current conditions text, which is data wearing the shape of a label. The compiler could not know: it sees one trace, and on that trace the anchor was right there.

$ verify weather.readForecastByZip --case "zipCode=10001" --case "zipCode=90210"

  pass  recorded  {"currentTemperatureF":78,…}
  fail  unseen    output_missing: currentTemperatureF at precededBy "Overcast"

  PINNED — works on the recorded value and fails on values it has not seen.

Beverly Hills was not overcast. Twenty-four hours later New York read “Fair”, and the capability failed on its own recorded ZIP too. It was never promoted: the model produced it, the compiler accepted it, and the gate refused it. A single green replay on the day of recording would have shipped it.

An anchor must be a label, not a value. inSameRowAs "ISIN" holds because every company article has an ISIN row. precededBy "Overcast" holds until the weather changes.

Run the whole thing yourself

The desktop app is the complete system, not a demo of it: give it a URL and a task, watch the agent work, take the wheel whenever you want, save what it learned as a capability, and replay that capability afterwards with no model involved.

Your API key stays on your machine. It is stored in the app’s own settings directory and never leaves it — there is no server in this product to send it to.

Download for macOS Source on GitHub
  1. Install and open it. The first launch downloads a private Chromium build for the agent to drive.
  2. Paste an AI Gateway key into Settings. Discovery needs it; replay does not.
  3. Give it a URL and a task in plain English, and watch. Take control at any step; hand it back when you are done.
  4. Save the run as a capability, then replay it with different inputs — that part never calls a model.

Builds are unsigned for now, so macOS will ask you to confirm the first launch via right-click → Open. Running from source is documented in the repository if you would rather.

What it does not do

Measured, not suspected — each is a real page it handles badly.

limitwhat happens
Bot wallsA major retailer returns 6 accessibility nodes — the CDN block page. Nothing is rendered to perceive.
Values with no labelSome pages put nothing label-shaped beside the number. No anchor choice fixes a page with no anchor.
Definition listsA <dl> presents neither a table row nor preceding label text. Needs a third relation kind.
Prompt cachingNot yet reusing the prompt prefix across steps. Pure cost, no correctness impact.

It works on pages whose structure carries meaning. It degrades on pages that are visually structured but semantically flat, and it does not work where a CDN decides it shouldn’t.
